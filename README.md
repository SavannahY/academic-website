# Zhengjie (Jane) Yang — academic website

Static academic website, hosted with GitHub Pages. No build step, database, server, or paid storage service is required.

## Editing

- `index.html`: biography, research, publications, and background.
- `styles.css`: responsive layout and typography.
- `script.js`: BibTeX copy buttons.
- `assets/`: public portrait, poster, and privacy-reviewed CV.

GitHub Pages publishes the repository root from the `main` branch. Commit and push edits to update the live site.

Only intentionally public website files belong in this repository. Do not add private research data, credentials, unpublished work, or a CV containing a private phone number or street address. The original private preview and personal CV are maintained separately.
